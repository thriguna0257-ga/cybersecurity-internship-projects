## 🔍 Project Highlights

### 01. Cyber Threat Landscape Brief – Protecting College Students
* Researched and summarized common cyber threats targeting university students, including credential harvesting, unsafe public Wi-Fi, and social engineering scams.
* Provided actionable defense strategies to help students secure academic and personal accounts.

### 02. Password Policy Audit & Staff Guide
* Audited password practices against modern authentication standards and documented remediation recommendations.
* Created a clear staff reference guide covering strong passphrase creation, password managers, and multi-factor authentication (MFA).

### 03. Phishing Email Analysis & Staff Awareness
* Analyzed phishing and legitimate email specimens for spoofed sender domains, artificial urgency, and deceptive hover URLs without triggering active payloads.
* Built a structured incident response workflow (**Report → Delete → Warn**) and a standalone one-page employee awareness quick-reference guide.

### 04. Home Network Security Audit
* Conducted a documented before-and-after security review with rollback baselines on an authorized home network.
* Enforced WPA2/WPA3 with a 22-character passphrase, disabled remote WAN administration and WPS, updated router firmware, and isolated IoT devices onto a Guest SSID.

### 05. Linux Permissions & Server Hardening
* Deployed an isolated Ubuntu Server VM in VirtualBox with pre-change recovery snapshots.
* Configured least-privilege user/group file permissions (`600`, `640`, `755`, `770`), disabled unnecessary services, enforced a default-deny UFW firewall, and hardened SSH access.
